GW2 Wayfinder

Privacy notice

Last updated: November 11, 2026

GW2 Wayfinder is a non-commercial fan project. There are no user accounts, no cookies set by this site, no analytics and no ads.

Your GW2 API key

  • Your key is kept in your browser: for the browser session, or on your device if you select "Remember my key". "Forget key" removes it.
  • Your browser sends the key to this server with each request. The server uses it only to read your account data from the official GW2 API run by ArenaNet.
  • The server does not store the key. It keeps a one-way hash of it in memory to link your requests to your chat and to limit how many messages can be sent.
  • The key is never sent to the AI model. You can delete the key at any time at account.arena.net/applications.

Your account data and messages

  • Account data is read from the GW2 API only when a question needs it.
  • Before anything is sent to the AI model, account, character and guild names are replaced with aliases such as Character_A. The real names are put back into the answer in your browser.
  • Your messages and the account data the assistant looks up, with names replaced, are sent to Anthropic, which provides the AI model (Claude). Anthropic processes them under its privacy policy.
  • Only names known from your account are replaced. Do not type other personal information into the chat.
  • Your chat is kept in the server's memory and deleted after one hour of inactivity or when the server restarts. It is never written to disk.

Other data

  • The server stores public game data, such as items, prices and wiki pages, in a cache. The cache contains no account data.
  • Wiki searches send only game terms, such as item names, to the Guild Wars 2 Wiki.
  • The server does not log IP addresses or messages. Error logs contain only the type of error.
  • The site is served through Cloudflare, which processes your IP address to deliver and protect the site and may set cookies needed for security. See the Cloudflare privacy policy.
